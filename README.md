# 돌려돌려

점심 메뉴, 벌칙, 주말 계획처럼 고르기 어려운 후보를 원판 룰렛으로 무작위 선택하는 한국어 웹앱입니다. 브라우저에서 바로 사용할 수 있는 정적 웹 프로젝트입니다.

## 주요 기능

- 후보 추가·삭제 및 전체 초기화
- 점심·벌칙·주말 기본 프리셋
- 후보 목록의 사용자 프리셋 저장·불러오기·삭제
- Canvas 2D 룰렛 애니메이션과 결과 표시
- 회전 중 중복 조작 방지, 당첨 순간의 결과 강조와 짧은 폭죽 효과
- 기본 꺼짐이며 설정 메뉴에서 켤 수 있는 결과 효과음
- 브라우저 `localStorage`를 이용한 후보, 프리셋, 효과음 설정 저장
- Pretendard 웹폰트, 다트 아이콘 로고, 데스크톱·모바일 레이아웃

## 기술 스택

- HTML
- CSS
- 바닐라 JavaScript
- Canvas 2D API 및 `requestAnimationFrame`
- `localStorage`, 선택적 Web Audio API
- jsDelivr CDN의 Pretendard 웹폰트

패키지 설치나 빌드 과정은 없습니다. Pretendard 폰트를 처음 불러올 때 인터넷 연결이 필요하며, 연결되지 않는 경우 브라우저의 기본 산세리프 글꼴이 사용됩니다.

## 실행 방법

1. 저장소를 내려받거나 복제합니다.
2. `index.html`을 브라우저에서 엽니다.
3. 로컬 정적 서버를 사용하는 경우 프로젝트 루트에서 `index.html`을 제공하도록 실행합니다.

현재 프로젝트에는 별도의 개발 서버 명령이나 패키지 스크립트가 설정되어 있지 않습니다.

## 사용법

1. 점심·벌칙·주말 프리셋 중 하나를 선택하거나 후보를 직접 추가합니다.
2. 룰렛을 돌립니다. 최소 2개, 최대 12개의 후보를 사용할 수 있습니다.
3. 회전이 끝나면 포인터가 가리키는 당첨 결과를 확인합니다.
4. 설정 메뉴에서 효과음을 선택하거나 항목 전체를 초기화할 수 있습니다.
5. 자주 사용하는 목록은 이름을 입력해 내 프리셋으로 저장하고 다시 불러옵니다.

후보 목록, 사용자 프리셋, 효과음 설정은 현재 브라우저에 저장됩니다. 다른 브라우저나 기기와 동기화되지는 않습니다.
